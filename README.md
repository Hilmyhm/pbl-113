# pbl-113
ini adalah main repository untuk setiap file projek kita dan saya harap semua tahu cara pakai git dan github agar setiap proses penyimpanan file di repository ini berjalan dengan baik

aturan repository:
1. jangan pernah malakukan eddit saat membuka file di dalam main branch.
2. jika ingin mengedit untuk melanjutkan projek atau hanya sekedari ingin coba2 tester lakukan branching dan pastikan branch tidak sedang di mainbranch.
3. jangan mengedit di branch milik orang lain kecuali pemilik sudah mengizinkan.
4. branch utama sudah diberi proteksi sehingga tidak bisa secara langsung melakukan merge atau penggabungan satu branch dengan branch lain.
5. jika ingin melakukan merge ke brach utama saat dirasa file sudah fix dan boleh dimasukkan ke main branch, ada satu tahapan sebelum branch lain dapat dimerge ke main branch yaitu pull request(ini hanya berlaku untuk merge ke branch utama)
6. pull request adalah tahapan dimana anggota lain, selain yang ingin melakukan merge, melihat dan mengoreksi perubahan yang akan terjadi jika merge dilakukan.
7. dan merge akan berhasil setelah pull request disetujui oleh anggota yang mengoreksi
8. minimal tau cara commit, branch dan merge juga pull request.
